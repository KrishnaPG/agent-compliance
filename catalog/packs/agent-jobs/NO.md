# Agent jobs pack, NO rules

Pack `agent-jobs` for base catalog 1.4.0. Scope: designs in which a program or harness starts AI agent jobs (an LLM with tools, run by the program without a person in the conversation): no agent in a mechanical path, minimal context, agent definitions, stable prompt prefix, caps and convergence, structured results. Loaded only when the project overlay names this pack. Each row is the whole rule.

| ID | Rule | Provenance | Test question |
|---|---|---|---|
| AJ-01 | Work that a deterministic program or an adopted tool can do with the same result (version control, running tests or checks, measuring, counting, sorting, comparing against a recorded value, a search for a known pattern, applying a recorded decision) runs as code and is never given to an agent job; an agent job is started only for work that needs judgement (design, review against prose rules, writing code or text), and it returns its result to the program, which does the mechanical steps before and after it. This is NO-05 and NO-06 applied to agent work. NA where the design starts no agent job. | Anthropic, "Building effective agents" (2024), https://www.anthropic.com/research/building-effective-agents: find the simplest solution possible and add complexity only when needed; workflows run LLMs and tools through predefined code paths. Convention: no agent in a mechanical path | Name each agent job the design starts and each step it is told to do: which of those steps would a program or adopted tool do with the same result? |
| AJ-03 | The model, effort, tools, turn limit and instructions of each kind of agent job are declared once, in the host's own agent-definition file, which the program names or passes by path; program code never sets or re-encodes them (NO-03, CF-07), so changing a job's model or tools is an edit of that file, not of code. The turn limit is the definition's (`maxTurns`); the one limit the program sets is the spend cap (`--max-budget-usd`, AJ-05). Program code adds only per-run values (paths, item ids, the job's data), the spend cap and the fixed start options other rules need (minimal mode, result schema), all read from configuration; it never sets a field this row lists. NA where the design starts no agent job. | Convention: native configuration stays native (NO-03) applied to agent hosts; Claude Code docs, "Subagents" (https://code.claude.com/docs/en/sub-agents: frontmatter `model`, `effort`, `tools`, `maxTurns`) and CLI reference (https://code.claude.com/docs/en/cli-reference: `--agent`, `--agents`) for what an agent definition is | Where are each job kind's model, effort, tools and turn limit declared, and which line of program code sets one of them? |
